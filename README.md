## Deskripsi Proyek
Proyek ini membangun sistem analisis geospasial berbasis Google Earth Engine (GEE)
dan Google Colab untuk menganalisis distribusi tutupan lahan dan kerapatan vegetasi di wilayah Sanggala Utara, Tana Toraja, Sulawesi Selatan, Indonesia.
